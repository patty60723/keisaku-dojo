## 1. 整體想法

坐禪時，禪堂、麻糬與計時數字是畫面主角。計時卡由上到下照順序讀：**時間 → 現在怎樣 → 今天累積 → 能做什麼**。操作集中在卡片下方同一列，容易找，但不搶場景。

整個 session 有一條原則：**禪堂不動，按鈕不跳**。會出現又消失的東西都放在不會推動別人的位置：
- 偵測說明放在按鈕列下面；
- 出堂確認的兩種文字疊在同一格；
- 合掌請打不顯示時，仍保留它的那一列。

| 修改前（6-1） | 修改後 |
|---|---|
| 頁首約 90 px：大標題＋副標各一行 | 頁首一行（標題、副標、齒輪），舞台上移 18–26 px。坐禪時副標淡出、標題轉為淡墨，高度不變 |
| 計時卡最後一列擠著「今日坐禪…被打…」「暫離」「出堂・結束」，被打次數一多就換行成直排 | 今日統計自成一行。按鈕列：左邊「暫離」是次要按鈕（框線），右邊「出堂・結束」是安靜按鈕 |
| 整段坐禪掛著朱紅色「⚠ 只能偵測是否切出畫面　為什麼?」 | 落座／回座時墨色說明 6 秒，然後收成「ⓘ 偵測方式」 |
| 出堂第一下只把字變成紅色「確定要出堂?」 | 變成有外框的按鈕「再按一次出堂」，底下一條線在 3 秒內縮完，時間到自動恢復 |
| 首次介紹時下方已有「25:00 報到中」；導覽時對話框和導覽卡各有一個「住持」名牌 | 介紹與導覽時不顯示計時卡；導覽時對話框讓位，只剩一個名牌 |
| 英文「Sitting · Round 1 · Study · Round 1/2」 | 「Sitting · Study · Round 1/2」（日文也修好） |

## 2. 七項的實作結果

### U1｜計時卡與操作區

- **結構：** 計時數字＋線香 → 狀態列（● 坐禪中 · 任務 · 第 n/m 炷）→ 今日統計（今日坐禪 N 分 · 被打 N 下）→ 虛線 → 按鈕列。
- **狀態列永遠一行：** 任務名稱太長時只截短任務名稱（加「…」，完整名稱在 `title`）。「坐禪中」與「第 n/m 炷」不會被截。任務名稱最多 12 個字（App 原本的限制）。
- **今日統計換行：** 只在「今日坐禪」「目標」「被打」三段之間換行，不在數字中間斷開。
- **按鈕：** 「暫離」用 6-1 的次要按鈕樣式，44 px 高。「出堂・結束」是安靜按鈕，44 px 高。暫離中，「回座」（主要按鈕）出現在原本「暫離」的位置。
- **顏色：** 卡片裡的被打次數由朱紅改成墨色。朱紅只留給被打的那一刻（狀態「被抓到了」、提示條）和場景本身。
- **驗證：**
  - 被打 12340 → 12342 下、12 字任務名稱、第 1/4 炷與第 2/4 炷，在 320×640、360×780、390×844、412×915、字體 130%、英文、日文下都看過；
  - 按鈕列都沒有拆成直排；
  - 沒有縮小字或觸控區。

### U2｜無平衡儀提示（依 Q6）

- **落座與回座時：** 卡片最下方出現墨色說明「ⓘ 只能偵測是否切出畫面」，6 秒後淡出，換成「ⓘ 偵測方式」。點一下可展開原本的完整說明，也可收起。
- **不會跳動：** 兩段文字疊在同一格，收起時卡片高度不變；說明又在按鈕列下面，所以不會推動任何按鈕。
- **沒有計時器：** 收起由 CSS 動畫完成，沒有新增 JS 計時器，也不碰偵測。
- **手動展開：** 使用者自己展開後，這次的短說明就結束，收起時不會再跑一次。
- **顏色與圖示：** 警告三角形與朱紅色移除，改成「ⓘ」加文字，不是只有圖示。
- **偵測沒有改：** 偵測方式、權限、分心判定、說明的內容都沒有改。

### U9｜出堂確認

- **第一下：** 安靜的字變成有墨色外框的按鈕「再按一次出堂」，底下一條線在 3 秒內縮完。第二下照舊出堂。3 秒後照原本的期限自動恢復。
- **按鈕大小固定：** 兩種文字疊在同一個按鈕裡，所以按鈕從頭到尾同一個寬度，不會擠到「暫離」。量測時確認狀態下「暫離」與「出堂」的位移都是 0。
- **減少動態：** 那條線不縮，只以半透明顯示。
- **邏輯沒有改：** 規則、3 秒期限、出堂流程都沒有改。

### U11｜頁首

- **一行：** 每個階段都是一行，含標題（1.375–1.625 rem）、副標與 44 px 齒輪。舞台因此上移：390 寬 102 → 80 px，320 寬 98 → 80 px，字體 130% 115 → 97 px。
- **坐禪時：** 落座、坐禪、暫離、休息與「該回座了」時，副標淡出、標題轉為淡墨。**高度不變**，所以 Round 5 的「開始坐禪時舞台不跳動」測試照樣通過。
- **為什麼不在坐禪時才縮：** 只在坐禪時縮矮會讓舞台在開始和結束時各跳一次，違反方案 D。所以高度在所有階段一起降，坐禪時只降視覺重量。
- **英文與窄螢幕：** 英文、字體 130% 或 320 寬時，副標會換到第二行。高度在所有階段相同，坐禪時第二行是空的（見第 5 節）。
- **其他：** 齒輪仍在原處。沒有做 6-6 的橫向修正。

### X1、U10｜首次進入與導覽

- **介紹與導覽時：** 第一次的自我介紹與四步導覽期間，不顯示計時卡。導覽結束，住持問「那麼，施主今天想做什麼呢？」時計時卡才出現。
- **重播導覽：** 從設定重播導覽時，若在報到階段也一樣；坐禪中重播則不隱藏計時卡。
- **只有一個名牌：** 導覽卡出現時，下方對話框隱形但保留位置，所以不會移動，也只看得到一個「住持」名牌。「暫離」與坐禪帳的單步提示也一樣。
- **原有流程不變：** 導覽步驟、略過開場、略過導覽與報到流程都沒有改。
- **已驗證的情況：**
  - 首次使用；
  - 略過導覽；
  - 回訪：計時卡照常顯示；
  - 介紹中重新整理：重新開始介紹，仍不顯示計時卡。

### U12｜狀態列

- **原因：**
  - 中文的狀態「坐禪中・第 N 炷」原本靠一條正規表示式去掉回合，再由後面的任務標籤顯示「第 n/m 炷」；
  - 英文「Sitting · Round N」與日文「坐禅中・第N炷」不符合那條規則，回合因此出現兩次。
- **修正：** 狀態只寫「坐禪中」（Sitting／坐禅中），回合只出現在任務標籤裡。三種語言都已截圖確認。

## 5. 仍存在的問題與合理例外

| 項目 | 說明 | 理由 |
|---|---|---|
| 頁首在 English、字體 130%、320 寬時是兩行 | 副標換到第二行，坐禪時第二行淡出成空白 | 頁首高度必須在所有階段相同，舞台才不會在開始與結束時跳動（方案 D 的測試）。仍比修改前矮 |
| 任務名稱被截短 | 320 寬＋字體 130% 時，12 字任務只顯示 1–2 字加「…」 | 狀態列保持一行，「坐禪中」與「第 n/m 炷」優先；完整名稱在 `title`，報到時也顯示完整的安排 |
| 今日統計換成兩行 | 320 寬＋字體 130%、且被打上萬下時 | 只在「今日坐禪」與「被打」之間換行，不拆數字 |
| 出堂按鈕的寬度 | 依「再按一次出堂」的寬度保留空間，所以安靜狀態時字的左右有些空白 | 換成確認狀態時不會擠到暫離；文字靠右對齊 |
| 偵測說明收起後，原本的空間仍保留 | 說明比「偵測方式」長時，下面多一點空白 | 高度不變，所以捲到頁尾時畫面也不會跳 |
| 「該回座了 → 下一炷」時出堂按鈕會移動 | 見第 4 節 | 對話框收起是原有流程；舞台不動 |
| 844×390 橫向的計時數字仍在畫面外 | 與修改前相同 | Q4 的橫向修正屬於 6-6，本批不做 |
