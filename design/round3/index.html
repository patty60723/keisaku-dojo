這一輪不再修補接縫，而是從剪影重新建立住持的造型語言。臉、耳朵、白眉、微笑、腮紅沿用；身體、袖子、香板、持握重新設計。動畫還沒做，正式版沒動。舊版保留：v2、v3。

這次的做法
  • 所有身體形狀都是穿過少數幾個點的平滑曲線，跟麻糬同一種柔軟的形狀語言；不再用幾何形狀拼接。
  • 袖子就是身體的兩側：從下巴下方的柔和肩膀垂下，構成外輪廓。袖口比下襬略寬，這個小台階讓手臂在純剪影裡也看得出來。
  • 三種姿勢共用同一個頭、同一件袍子、同一組袖子外緣和雙腳；姿勢只改變袖子內側、手和香板。
  • 內部線條只留有用的：前側袖的前緣（手臂在哪）、袖子交疊、衣領交叉、手的手指。

07.5姿勢修正（Round 3.1）：袖手、舉香板

規則調整
  • 固定：頭身比例、軀幹（袍子）體積、肩關節在軀幹上的位置、頭與臉、雙腳。
  • 允許改變：上臂、手肘、前臂、手腕的位置；袖子外輪廓與袖袋跟著手臂動。先決定手臂怎麼擺，再畫袖子，最後才放香板。
  • 站姿、垂放香板兩個姿勢沒有改動。

A　袖手：修改前／修改後

三張同一個比例、同一個視角。修改後：上臂自然垂在身側、肩膀不聳；手肘往前彎，前臂在腹前交疊；近側袖口蓋在遠側前臂上（袖端那條深色細縫是開口的側面，遠側的手從這裡伸進去）；兩個袖袋都在手肘下方最低，往手的方向收起。手肘內側只留一條順著彎曲方向的布紋。

B　舉香板：修改前／修改後

修改前是把香板轉到角度、再把手放到握柄旁，手肘和前臂沒有交代。修改後由手臂決定香板：肩膀 → 手肘往外下方 → 前臂往上偏前 → 袖子順著前臂滑下、露出手腕 → 拳頭握住握柄。握柄大致垂直於前臂，手腕再往拇指側偏一點，所以香板自然往後斜、不擋臉；板身的重量落在手的上後方。手肘把袖子往外撐，袖袋從前臂直直垂下，比站姿短。

08動畫準備（Phase 5）

動畫規格更新
  • 移除舊限制：「所有姿勢都固定袖子外輪廓」不再成立（Round 3.1 起）。
  • 固定的：頭身比例、軀幹體積、肩關節在軀幹上的位置、頭與臉、雙腳、配色。
  • 會動的：手肘、前臂、手腕依姿勢改變；袖子外輪廓與袖袋跟著手臂變形、垂墜。
  • 連動順序：肩 → 肘 → 腕 → 手 → 香板。香板是手的子物件，只會跟著手腕轉，加上手腕本身的小幅彎曲（約 ±30°），從不自己旋轉。
  • 袖子是布，不是骨頭：不綁在骨架上旋轉，而是在兩個關鍵姿勢的袖子輪廓之間變形（兩邊重新取樣成同樣的點數再內插），用和關節同一條時間曲線驅動；袖袋晚 1–2 格到位，表現垂墜。
  • 可以有 Q 版誇張：揮下時香板與前臂可以拉長、加速度線、身體壓扁；靜止姿勢維持已驗收的外觀。

實作計畫

  1. 骨架與關鍵姿勢資料：每個姿勢記錄肩、肘、腕、拳頭位置與袖子輪廓。已具備：站姿、袖手、垂放、舉起、預備、揮下、收勢（見上方「關鍵姿勢」）→ 等你確認。
  2. 連動與變形：香板由拳頭與手腕角度算出；袖子輪廓重新取樣後內插；袖袋延遲。先在設計頁做成可以播放的預覽。
  3. 接到 Round 1 原型（design/round1/proto.html）：用新住持替換舊住持，套上第 1–7 段的時間表，你在手機上試。
  4. 確認後才進正式版：沿用正式版現有的計時與偵測邏輯，只換住持的畫法與動作。
