# 香板禪堂

可愛的番茄鐘專注 App。靈感來自禪寺的坐禪:巡香的師父拿著香板在禪堂裡來回走,
有人打瞌睡或分心,就會被「啪」地打一下。

中文名是「香板禪堂」,日文版是「警策道場」,英文版是「Keisaku Dojo」。repo 名稱 `keisaku-dojo` 不變。

## 玩法

- 打開後先跟住持報到(RPG 式對話):說今天要做什麼、每炷多久、坐幾炷、休息多久,
  住持會複述一次,再問你「準備好了嗎?」。流程細節見 [`docs/onboarding-spec.md`](docs/onboarding-spec.md)。
  - 每炷可選 15 / 25 / 40 / 50 分或自訂 5–120 分;可坐 1–4 炷或自訂到 8 炷;休息 5 / 10 / 15 分或自訂 1–30 分。
  - 回訪可以直接選「跟上次一樣」,或把常用的設定存起來(最多 3 組)。
  - 第一次來,住持先用幾句話介紹禪堂在做什麼(講到香板時會真的去柱子邊拿起來),可以按「略過開場」。
    接著是新手導覽:畫面變暗,依序亮出堂規木牌、坐禪帳、收藏冊(中間的掛軸)和齒輪,一定要點亮起來的地方才會繼續(點了就會打開它),也可以「略過導覽」。
    設定裡可以「重看導覽」。
  - 「略過開場」只在介紹時出現;選設定的步驟不能略過,但有「跟上次一樣」可以一鍵沿用。
  - 確認設定的「我要改」和第一炷前「準備好了嗎」的「改設定」,都可以只改其中一項(要做的事、每炷多久、坐幾炷、休息多久)。
  - 還沒準備好可以按「再等一下」,住持去喝杯茶,一分鐘後回來再問。
- 按「準備好了」後,3 秒內把手機平放在桌上(螢幕朝上朝下都行),或立在手機架上。App 會記住這個角度。
- 坐禪中住持會一直巡堂:
  - **拿起手機**(平衡儀偵測到傾斜或晃動超過 0.6 秒)→ 住持衝過來「啪」。放回原位才算回座;一直不放,每 20 秒再補一下。
  - **切到別的 App 或分頁**超過 2 秒 → 回來時被打;離開超過 90 秒會多打一下。
- **背景聲音**:在「設定」選雨聲、海浪、森林或和弦風鈴,也可以勾「加上輕柔的和音」
  (幾個慢慢換的和弦,偶爾一兩聲高音,可以單獨播或疊在自然聲上),可以調音量、先試聽。
  止靜三鐘敲完才慢慢淡入,開靜時淡出,休息時不播。全部用 Web Audio 即時合成,沒有音檔,離線也能用。
- **暫離**:坐禪中臨時有事,可以按「暫離」暫停計時,每炷一次,不算被打。回來按「回座」,把手機放好就從暫停的地方繼續。
  第一次按「準備好了」前住持會提一次;第一次被打之後,畫面會亮出「暫離」按鈕說明它的用途。
- 炷與炷之間休息時住持去喝茶,手機隨便用。休息結束住持會再問一次準備好了沒;回來時如果已經超過休息時間,住持會說超過了幾分鐘(記進坐禪帳)。
  - 可以在設定打開**休息結束通知**。網頁沒有伺服器,只能在 App 還醒著時發通知,手機把背景網頁凍結時可能會晚到或沒有。
- 鐘聲:每炷開始敲**止靜三鐘**,結束敲**開靜一鐘**,休息結束敲兩鐘叫你回座。
- 「合掌請打」:真正的禪堂裡也可以自己合掌請師父打一下提振精神,不算扣分。
- 一輪坐完會蓋章(不動 / 精進 / 喝),按「分享」可以把結算卡(禪堂畫面、印章、禪語)存成 1080×1350 的圖片或直接分享。
- **每日目標**:在設定選一天要坐滿幾炷(2 / 4 / 6 / 8),計時卡片會顯示進度,達成的日子坐禪帳上多蓋一個「達」。
- 禪堂裡左牆掛著「堂規」木牌、右柱掛著一本大福帳(坐禪帳)、中間是掛軸(收藏冊),點了就會打開;右上角的齒輪是設定。四個都是彈出面板(不換頁,坐禪中打開也不會中斷計時),
  像手卷一樣從中間往兩邊展開,收起時卷軸會飛回木牌、帳簿或齒輪。連續兩天以上,坐禪帳上會掛一個紅色天數章。深色模式是夜裡的禪堂:方窗下的行燈會點亮,兩扇窗的月光落在榻榻米上。外觀選「隨時間」時,白天淺色、天黑深色,日出和日落前後各約 40 分鐘是黃昏:窗外夕陽天空和一顆低垂的紅日,室內整體偏暖。
- **悟之窗與迷之窗**:仿京都源光庵,掛軸左邊是圓窗(悟之窗)、右邊是方窗(迷之窗),左右對稱。窗外跟著月份換季:春櫻(花瓣飄落)、夏竹(夜裡有螢火蟲到處飛)、秋楓(紅葉落下)、冬梅和雪。點圓窗或方窗,住持會說兩扇窗的由來。
- **語言**:中文、日本語、English。預設跟著手機語言(中文手機用中文、日文手機用日文,其他用英文),也可以在「設定」的「語言 / Language」手動切換。
- **收藏冊**:點中間的掛軸打開,有「掛軸 / 四季 / 配件 / 表情」四頁。坐滿的炷越多、連續天數越長,能換的掛軸(14 幅)和麻糬的配件(21 件)就越多,還沒拿到的會寫條件和還差多少。配件分成「頭 / 身體 / 配飾」三格,每格戴一件、三格可以同時戴,再點一次就拿下來;被香板打的時候,頭上的東西會有反應(帽子歪掉、小鳥嚇得飛一圈、花瓣掉下來…),每次都有點不一樣。日文版的掛軸下面附讀音,英文版附意思。「表情」頁收集麻糬的 12 種表情(睏、得意、嚇一跳、淚眼、滿足、害羞、發呆、專注…),每種在自己的時機出現,看過就收進冊子,每種表情都會小小地動;收到的表情可以選一個當報到和休息時的「平常」表情。坐滿一炷拿到新東西時,結算卡會寫出來,住持會問要不要掛上或戴上。坐禪中只能看不能換。收藏是從坐禪帳算出來的,匯入備份就會回來。外觀、平衡儀和鐘聲、通知、每日目標、紀錄的備份都在「設定」裡。
- **坐禪帳**:打開月曆,有坐禪的日子會蓋印章(坐得越久越濃,75 分以上蓋合掌章,
  坐滿又沒被打蓋「不動」章),點某一天看明細(大印章旁會寫這是什麼章),也會顯示連續天數。「統計」分頁像一頁功課簿:選七日、三十日或全部,住持先說一句評語(跟前一段比較,語氣永遠是鼓勵),下面是帳簿式的坐禪時間、坐滿炷數、被打次數,每天坐了多久畫成一排線香(今天那根點著),點一根會跳出籤紙寫明細,最後是各項目花了多少時間。紀錄存在瀏覽器裡,
  可以在「設定」匯出 / 匯入備份。規格見 [`docs/journal-spec.md`](docs/journal-spec.md)。

## 執行

上線的 `index.html` 是組出來的單一檔案,**不要直接改它**,要改 `src/` 裡的原始檔:

```sh
python3 build.py            # src/ → index.html
python3 build.py preview    # src/ → preview.html(左上角有「預覽版」標籤,給上線前比較用)
python3 build.py debug      # src/ → debug.html(除錯版:收藏全部解鎖、用自己的紀錄,浮動面板可切季節、日夜、打一下、坐站)
python3 build_lab.py        # 改了聲音引擎時,重新產生 soundlab.html
python3 -m http.server      # 在 http://localhost:8000 試(Service Worker、通知要透過 http:// 才會啟用)
```

**自動測試**(`tests/`,用 Playwright 在手機尺寸上跑完整流程,約 3 分鐘):

```sh
npm install                     # 第一次:裝 Playwright
npx playwright install chromium # 第一次:下載測試用的瀏覽器
npm test
```

測試會自己開本機伺服器,截圖和存下的分享圖放在 `tests/output/`(不進版本控制)。
其中 `build.test.mjs` 會檢查 `index.html`、`soundlab.html` 跟 `src/` 組出來的一致,忘了 build 就會失敗。

- **電腦上試**:沒有平衡儀,會自動改用「離開畫面」偵測。
- **手機上用**:平衡儀(DeviceMotion)和 PWA 都需要 HTTPS,最簡單是開 GitHub Pages:
  Settings → Pages → Source 選 `Deploy from a branch`,branch 選 `main` / `/ (root)`。
  免費帳號的 Pages 需要 repo 是 public。
- iPhone 第一次按「準備好了」時,Safari 會問能不能存取「動作與方向」,要按允許。

## 裝到主畫面(PWA)

- **iPhone**:用 Safari 打開 → 下方「分享」→「加入主畫面」。
- **Android / 電腦版 Chrome**:網址列的安裝圖示,或「設定」裡的「把禪堂裝到主畫面」按鈕。
- 裝好後會以全螢幕 App 的方式開啟,第一次開過之後沒有網路也能用。

PWA 相關檔案:

| 檔案 | 用途 |
|---|---|
| `manifest.webmanifest` | App 名稱、圖示、全螢幕顯示 |
| `sw.js` | 離線快取:頁面網路優先(有更新就拿新的),字型和圖示快取優先 |
| `icons/og-v2.png` | 分享連結時的預覽圖(1200×630),網頁 `<head>` 裡的 Open Graph 標籤指向它。換圖時一樣把檔名版本加一 |
| `icons/` | `icon-v2.svg` 是原稿,PNG 從它轉出來(192、512、留安全邊的 maskable 512、iPhone 用的 180)。檔名後面的 `-v2` 是圖示的版本 |

改了 manifest 之後,記得把 `sw.js` 裡的 `VERSION` 加一,舊的快取才會被清掉。

**換圖示時,檔名的版本號也要加一**(例如 `-v2` → `-v3`),並一起改 `manifest.webmanifest`、`sw.js` 的檔案清單和 `build.py` 裡的 `<link>`。
已安裝的 App 圖示是手機系統管的:Android 的 Chrome 大約一天最多檢查一次 manifest,而且要從主畫面打開 App 時才會檢查;檔名沒變的話,很容易被當成沒變。
iPhone 的主畫面圖示則是加入當下就固定了,要刪掉重新「加入主畫面」才會換。

manifest 的 `id` 要寫完整路徑 `/keisaku-dojo/`:寫 `./` 會被解析成網域根目錄,
跟同一個 `github.io` 網域上的其他網頁 App 撞 ID,Chrome 可能會誤以為已經安裝過。

## 隱私

紀錄和設定只存在使用者手機的瀏覽器(`localStorage`)裡,不會上傳到任何地方,沒有追蹤、統計或廣告。
平衡儀(動作感測器)只用來即時判斷手機有沒有被拿起來,讀到的數值不會被保存。App 裡的堂規和設定也有寫這段說明。

## 上版資訊

**目前版本:v20(2026-10-20)**,線上網址 <https://patty60723.github.io/keisaku-dojo/>。
版本號就是 `sw.js` 裡的快取版本 `VERSION`。

**上版步驟**

1. 改 `src/`,執行 `python3 build.py`(改到聲音的話加跑 `python3 build_lab.py`)。
2. 需要先給人看的改動,用 `python3 build.py preview` 推 `preview.html`,確認後再刪掉。
3. `sw.js` 的 `VERSION` 加一,已安裝的 App 才會清掉舊快取、換成新版。設定裡顯示的版本號也是從這裡來的,build 時自動帶入。
4. 跑 `npm test` 全部通過,再用 `python3 -m http.server` 在手機上走過一次,然後 commit、push 到 `main`。
5. GitHub Pages 約 1–2 分鐘後更新。已安裝的 App 重開就是新版;還是舊畫面的話,完全關掉再開一次。

## 聲音試聽台

`soundlab.html`(上線後在 `https://patty60723.github.io/keisaku-dojo/soundlab.html`)是調背景聲音用的工具頁:
跟 App 用同一份聲音程式,可以直接播各種聲音、拉滑桿調參數,再按「複製設定」把數值帶回 `src/app.js` 裡的 `SND`,然後重新 build。
